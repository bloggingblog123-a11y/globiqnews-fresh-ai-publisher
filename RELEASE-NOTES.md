# GlobiqNews Fresh AI Publisher 6.0.0

This major update creates researched original Drafts for human review. All automatic article publication has been removed. Even a Rank Math score of 100 leaves a Draft; publish manually in WordPress.

- Adds optional GDELT discovery alongside independent RSS/Atom, Source URL and Manual URL workflows.
- Adds evidence-backed fact sheets, independent plans, source comparisons, AI factual review and an internal Added Value Score. No automatic claim of plagiarism-free or independently verified content.
- Protects the final writer with system instructions and a fact-only source boundary; allows shorter articles without filler or forced SEO templates.
- Makes images optional, default OFF for new installs, while preserving existing saved choices. ON permits two original WebP images; OFF makes zero generation calls. Manual media remains protected.
- Retains genuine Rank Math analysis and up to three quality-checked SEO improvements. Local Node/remote scoring remains optional.
- Preserves settings, API keys, existing categories, queues and unchanged schedules. Archives obsolete publication preferences once.
- Adds private reports, manual review actions, redacted logs and improved source, lock, batch and permission safeguards.

Validation: 175 WordPress assertions and six scoring-service tests passed locally. Provider/source tests use controlled fixtures; actual WordPress, Rank Math analysis and generated WebP files are exercised. See TEST-REPORT-6.0.0.md for limits and detailed evidence.

Install using **Replace current with uploaded**; do not delete the previous plugin. This is a review candidate for staging. No live website deployment or stable GitHub release is included in this delivery.
