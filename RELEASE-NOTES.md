## 5.29.0

- Adds GitHub plugin updates from this repository using WordPress's normal update interface.
- Accepts published stable releases only, with the packaged plugin ZIP attached.
- Preserves the 80+ Rank Math article publishing fix, draft diagnostics and Save Settings button.
- Retains existing WordPress option names, API keys, category settings and saved articles.

Install this updater-enabled version once using Upload Plugin → Replace current with uploaded.
Enable auto-updates for the plugin on WordPress's Installed Plugins page to receive future releases automatically.

The updater and article publishing logic were checked locally. A live WordPress upgrade
on the user's website has not been performed.
